# Smart Gym Repetition Counter

A simple web app that counts your push and pull exercises using your webcam and AI pose detection.

## 🏋️ Features

- Counts push and pull exercises in real-time
- Tracks left and right arms separately
- Works on both desktop and mobile devices
- Simple and intuitive interface

## 🚀 How to Use

1. Open the app in your web browser
2. Select an exercise (Push or Pull)
3. Allow camera access when prompted
4. Position yourself in front of the camera
5. Start exercising!

## 📱 Mobile Friendly

- Responsive design works on all screen sizes
- Touch-friendly interface
- Optimized for both portrait and landscape modes

## 🛠️ Technologies Used

- HTML, CSS, JavaScript
- MediaPipe Pose Detection
- Webcam API

## 📝 Note

For best results:
- Ensure good lighting
- Keep your whole body in frame
- Face the camera directly
